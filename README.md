Описание программы
Данная программа на языке C выполняет три задания:

Задание 1: Вычисляет синус угла, заданного пользователем в градусах. Перевод в радианы осуществляется по формуле 
gr⋅π/180. Результат выводится с точностью до 6 знаков.

Задание 2: Вычисляет значение сложной математической функции (Вариант 29) от переменной 
x (вводится пользователем) и константы y=2×10^−5
 . Результат выводится с точностью до 3 знаков.

Задание 3 (а): Проверяет условие «только одно из чисел А и В четное», где 
A и B — целые части чисел 
x и y соответственно. Выводит 1 (истина) или 0 (ложь).

Описание логики кода (как написан код)
Подключение библиотек и директив:
#define _CRT_SECURE_NO_WARNINGS — отключает предупреждения безопасности Visual Studio для функции scanf.
#define _USE_MATH_DEFINES — позволяет использовать константу M_PI из библиотеки <math.h>.
Подключаются <stdio.h> (ввод/вывод), <math.h> (математические функции), <locale.h> (русский язык в консоли).

Задание 1:
Объявляется переменная gr типа double.
С помощью scanf считывается значение угла.
Угол переводится в радианы: rad = gr * M_PI / 180.0.
Вызывается функция sin(rad) и результат выводится через printf с форматом %.6f.

Задание 2:
Объявляются переменные x и y. Пользователь вводит x, а y жестко задается как 2e-5.
Формула разбивается на части для удобства:
numerator1 = 3.0 + exp(y - 1.0) (числитель первой дроби).
denominator1 = 1.0 + (x * x) * fabs(y - tan(x)) (знаменатель первой дроби; используется fabs для модуля).
fraction1 = numerator1 / denominator1 (первая дробь).
fraction2 = 50.0 * pow(fabs(y - x), 3.0) / 3.0 (вторая часть формулы).
Итоговый результат: F = fraction1 + fraction2.
Вывод x, y и F (с форматом %.3f).

Задание 3:
Переменные x и y приводятся к целочисленному типу int (отбрасывается дробная часть) и сохраняются в A и B.
Условие «только одно четное» записывается через логическое ИЛИ (||) двух условий: (A четное И B нечетное) ИЛИ (A нечетное И B четное).
Результат логического выражения (1 или 0) выводится на экран.
